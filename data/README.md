# Data directory

This directory contains the fixed, redistributable network inputs needed to reproduce the reported NBVK analyses.

The `network_inputs/` directory contains STRING-derived edge tables, node metrics, identifier-mapping audit results, and the ARG1/LCN2/LTF anchor-membership table. These files are computational inputs and do not establish direct compound-target binding.

The `geo/` directory documents the five reported GEO cohorts and contains complete gene-level derived effect tables. Raw GEO expression files are retrieved from the original accessions and are not duplicated.

Raw GEO downloads are not duplicated here and should be obtained from the original GEO accessions. Redistribution of all third-party records remains subject to the corresponding source database terms.
