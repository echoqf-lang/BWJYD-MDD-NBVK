# Analysis code

Only scripts that generate results reported in the final manuscript should be included here. Superseded, exploratory, hard-coded, or failed workflows must be kept outside the public release.

- `geo/`: GEO retrieval, preprocessing, cohort modelling, meta-analysis, and brain-validation scripts.
- `nbvk_v1/` and `nbvk_v2/`: network-based virtual-knockout analyses and tests.
