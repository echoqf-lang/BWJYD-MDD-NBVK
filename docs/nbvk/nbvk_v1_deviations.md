# NBVK预注册偏离清单

冻结预注册：`2026-07-26-nbvk-analysis.md`

## 不影响主要统计定义的实现修复

1. 使用R/igraph 2.3.3而非Python执行最短路径，以满足计算可行性；图、距离和统计定义未改变。
2. 沙箱不能返回CPU核心数，工作进程固定为8。
3. 最大连通分量边数经输入文件核实为13,416，修正了运行前的错误预估断言13,412。
4. 显式解析CSV中的文本布尔值。
5. 首次推断表错误地使用了`ave(..., method="BH")`；完整零分布与经验P值未受影响。当前FDR已通过显式分组BH重建并独立复算。
6. 对Monte Carlo重复抽到的同一节点集合仅精确计算一次，再按原抽样频数映射回10,000行；统计分布不变。

## 尚未完全按预注册输出的项目

1. 主结果保存了删除前后倒数距离总和，但没有另列“平均倒数距离”和“绝对变化”；两者可由已保存字段与保留节点对数直接派生。
2. 保存了`components_after`，但没有单独字段`components_change`；主LCC删除前为1，因此可直接派生。
3. “候选节点跨预设核心层的直接边损失”没有写入NBVK观察结果表；相关一阶邻居及核心成员关系已存在于Figure 3底层数据，但未合并进NBVK结果。
4. 完整1,291节点网络及去除最高degree 1%节点分析目前只报告观察效应，没有各自置换推断。
5. score≥0.400与score≥0.700加权网络已经补充各自重建匹配池的拓扑匹配置换推断，但未补充均匀随机基线。

## 事后探索性分析

以下分析均在看到主结果及红队意见后实施，不属于确认性结果：

1. 按观察组合内部边数条件化既有拓扑匹配零分布；
2. 统计LCN2–LTF直接边、共享邻居和三节点协同贡献比例；
3. 红队进行的匹配池精确枚举和额外阈值扫描。

这些结果仅用于压力测试和限制解释，不得用于替代或“修复”预注册主要假设。
