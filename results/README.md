# Results

This directory contains the frozen NBVK v1 and NBVK v2 outputs used in the manuscript and supplementary tables.

- `nbvk_v1/primary/`: prespecified observed values, inference tables, matching pools, hub reference, and complete primary null distributions.
- `nbvk_v1/sensitivity/`: alternate matching, network-definition, weighting, and random-seed sensitivity outputs.
- `nbvk_v1/exploratory_posthoc/`: analyses performed after inspection of the primary results; these must not be presented as confirmatory.
- `nbvk_v2/`: combination-structure matching inputs and global-damage inference results.
- `geo/`: cohort metadata, ARG1/LCN2/LTF cohort effects, and the corresponding whole-blood meta-analysis summary.

Complete null distributions are intentionally retained to permit independent recalculation of empirical P values and adjusted results.
